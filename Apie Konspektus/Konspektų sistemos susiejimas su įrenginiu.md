#### Įvadas
Naudotis šia sistema yra būtina ją susieti su programa Obsidian bei šią programą paruošti su git papildiniu konspektų atnaujinimui.
#### Instaliacija
Programos obsidian instaliavimo failus galima gauti svetainėje https://obsidian.md/download
Pasirenkamas instaliavimo failas tinkantis kompiuterio operacinei sistemai, pvz. Windows arba Mac, ir sekamos instrukcijos paleidus instaliaciją
#### Failų aplankai
Pabaigus instaliuoti programą yra būtina susikurti failų aplanką. Pasirenkama aplanko vieta ir pavadinimas, bei aplankas yra sukuriamas.
#### Git programos instaliacija
Papildinys kuriuo remiasi failų atnaujinimas turi turėti suinstaliuotą Git programą.
https://git-scm.com/install/windows
Paleidus instaliavimą visi nustatymai paliekami taip pat, priėjus žingsnį `Adjusting your PATH environment` pasirenkamas `Git from the command line and also from 3rd-party software` bei pabaigiama instaliacija.
#### Git papildinys
Konspektus gauti ir atnaujinti yra būtina juos susieti su internete esančia failų talpykla. Atidaromi programos nustatymai esantys apačioje kairėje pusėje, į dešinę nuo anksčiau pasirinkto aplanko pavadinimo.
Atidaromas "Community plugins skyrius", bei būtina paspausti "Exit Restricted mode" mygtuką prie "Allow community plugins".
Spaudžiamas mygtukas "Browse" bei paieškoje įvedama git. Suradus reikia suinstaliuoti papildinį Git bei jį įjungti
#### Susiejimas su talpykla
Įvykdžius visus etapus galima su talpykla susieti programą. Spaudžiami klaviatūros mygtukai `Ctrl+P` arba `>_` mygtukas esantis programos šone. Į paieškos langą įvedamas "clone" ir paspaudžiama komanda `Git: Clone an existing remote repo`.
Duodamos instrukcijos `Enter remote URL`, šiame etape įvedamas saitas `https://github.com/RobertasSkirka/KTUKONSPEKTAI.git` bei spaudžiamas mygtukas `Enter`.
Kitame etape yra įvedamas koks nors pavadinimas aplankui kuris turės konspektus, toliau paprašius `Specify depth of clone` spaudžiama `Enter`. Įvykdžius instrukcijas konspektai atsiras įvardintame aplanke.
#### Telefonams
Instaliacija išlieka panaši į skirtą kompiuteriams, tik nebūtina papildoma git programos instaliacija bei įvykdžius komandą `Git: Clone an existing remote repo` būtina įvesti tik Github saitą bei kituose etapuose pakanka spausti `Enter` arba naujos eilutės mygtuką.
